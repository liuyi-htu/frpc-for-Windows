Info
Project strengths
  • Lightweight web console for start, stop, logs, config, and proxy management.
  • Minimal-memory mode can close the web backend after frpc is running.
Usage
  • Fill server information in Basic settings.
  • Add proxies in Proxy management.
  • Return home and click Start; check Logs when troubleshooting.
Minimal-memory mode
  • After entering minimal-memory mode, the web console closes and cannot be accessed directly.
  • To restore the web console, reopen frpc-web from the install directory.
  • Then open the default address again: http://127.0.0.1:62930
